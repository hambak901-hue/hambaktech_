## 1. PRODUCTION ARCHITECTURE OVERVIEW

The production architecture is specifically designed for high-performance, cost-effective, and resilient operation on cPanel/shared hosting without requiring an active Node.js server daemon:

1. **Frontend**: Static export generated by Next.js (`npm run build` -> `out/`).
   - All client pages (`/`, `/about`, `/services`, `/academy`, `/shop`, `/contact`, `/signin`, `/signup`, `/dashboard/*`, `/admin/*`) compile to optimized HTML, CSS, and JS bundles.
   - Clean URLs and client-side routing are managed via Apache `.htaccess` rewrite rules.
2. **Backend API**: Native PHP 8.1+ REST API front-controller located at `api/index.php`.
   - All endpoints (`/api/*`, `/api/v1/*`) are routed to `api/index.php` using Apache `mod_rewrite`.
   - Pure PHP native standard library architecture (zero Composer dependencies, zero framework overhead).
3. **Database**: MySQL 8.0+ or MariaDB 10.4+ with InnoDB engine and ACID transaction isolation.
4. **Security Isolation**:
   - Zero provider API keys or credentials in client bundles or public HTML.
   - All payments, NIN/BVN queries, and telecom purchases are executed via server-side proxies.
   - Direct web access to `.env`, `php-backend/`, `storage/`, and `database/` is blocked at the web server level.

## 4. PRODUCTION EMAIL & SMTP ARCHITECTURE

### Email Transport
- **Implementation**: Pure PHP standard-library RFC 5321/5322 socket client (`php-backend/src/Services/EmailService.php`).
- **External Dependencies**: Zero (operates natively without PHPMailer or Composer).
- **Socket Protocol**: Supports `ssl://` direct over port 465 or `tcp://` with opportunistic `STARTTLS` negotiation over port 587.
- **Fail-Safe Behavior**:
  - In development/testing without SMTP credentials, emails are written to `storage/logs/email.log` with sensitive OTP codes redacted.
  - In production without SMTP credentials, requests return HTTP 503 Service Unavailable without crashing or fabricating delivery.

### Email Configuration Variables
- `SMTP_HOST` / `MAIL_HOST`: Outgoing SMTP hostname (`mail.hambaktech.com.ng`).
- `SMTP_PORT` / `MAIL_PORT`: Port (`465` for SSL, `587` for TLS).
- `SMTP_USER` / `MAIL_USERNAME`: Full email address (`support@hambaktech.com.ng`).
- `SMTP_PASSWORD` / `MAIL_PASSWORD`: Email account password.
- `SMTP_SECURE` / `MAIL_ENCRYPTION`: `ssl` or `tls`.
- `SMTP_FROM_EMAIL` / `MAIL_FROM_ADDRESS`: `support@hambaktech.com.ng`.
- `SMTP_FROM_NAME` / `MAIL_FROM_NAME`: `"HAMBAKTECH & SERVICES"`.
- `SMTP_REPLY_TO`: `support@hambaktech.com.ng`.
- `ADMIN_ALERT_EMAIL`: `admin@hambaktech.com.ng`.
- `SUPPORT_NOTIFY_EMAIL`: `support@hambaktech.com.ng`.

### Documented Email Flows
1. **Account Registration / Welcome**: `sendWelcomeEmail($email, $name)`
2. **Email Verification**: `sendEmailVerification($email, $token, $name)` -> Link: `https://hambaktech.com.ng/verify-email?token={token}`
3. **Password Reset**: `sendPasswordReset($email, $token, $name)` -> Link: `https://hambaktech.com.ng/reset-password?token={token}` (Expires: 2 hrs)

## 8. STEP-BY-STEP CPANEL POST-UPLOAD PROCEDURE

1. **Step 1 — Create Database**: Under cPanel **Databases**, launch **MySQL Database Wizard** and create database `hambakte_portal`.
2. **Step 2 — Create User**: Create database user `hambakte_dbuser` with a 24+ character password.
3. **Step 3 — Assign Privileges**: Grant `ALL PRIVILEGES` to `hambakte_dbuser` on `hambakte_portal`.
4. **Step 4 — Import Canonical Schema**: Open **phpMyAdmin**, select `hambakte_portal`, click **Import**, choose `database/schema.sql` (creates 39 base tables).
5. **Step 5 — Import Migrations**: In phpMyAdmin, import `database/migrations/2026-09-28-identity-telecom.sql` (creates `identity_verifications` and `telecom_transactions`).
6. **Step 6 — Import System Seeds**: In phpMyAdmin, import `database/seed.sql` (creates RBAC roles, permissions, categories, initial services). Total table count must equal **41**.
7. **Step 7 — Configure Environment**: Copy `config/production.env.template` to `/home/username/.env`. Set file permissions to `chmod 600 .env`.
8. **Step 8 — Configure PHP**: In cPanel **Select PHP Version**, choose **PHP 8.1**, **8.2**, or **8.3**.
9. **Step 9 — Enable PHP Extensions**: Ensure `pdo_mysql`, `curl`, `mbstring`, `openssl`, `json`, and `fileinfo` are enabled.
10. **Step 10 — Document Root**: Ensure the web root is mapped to `/home/username/public_html/`.
11. **Step 11 — Verify `.htaccess`**: Ensure `.htaccess` is present in `public_html/` with clean URL rewrites and directory blocks.
12. **Step 12 — Storage Permissions**: In cPanel File Manager, ensure `storage/logs/`, `storage/cache/`, and `storage/uploads/` are writable (`chmod 755`).
13. **Step 13 — Upload Directory Security**: Verify `storage/uploads/.htaccess` and `public_html/uploads/.htaccess` are present (disables script execution).
14. **Step 14 — SSL / AutoSSL**: In cPanel **SSL/TLS Status**, click **Run AutoSSL** to issue certificate for `business.hambaktech.com.ng`.
15. **Step 15 — Application URL**: In `.env`, ensure `APP_URL=https://business.hambaktech.com.ng`.
16. **Step 16 — API URL**: In `.env`, ensure `NEXT_PUBLIC_API_BASE_URL=https://business.hambaktech.com.ng` (or relative `""`).
17. **Step 17 — CORS Policy**: Ensure `CORS_ALLOWED_ORIGINS=https://business.hambaktech.com.ng,https://www.business.hambaktech.com.ng`.
18. **Step 18 — SMTP Account**: In cPanel **Email Accounts**, create `support@hambaktech.com.ng`.
19. **Step 19 — Payment Gateways**: In `.env`, enter live Paystack and Flutterwave keys.
20. **Step 20 — Identity Gateways**: In `.env`, enter live Veripine API key.
21. **Step 21 — Telecom Gateways**: In `.env`, enter live VTpass (`VTPASS_LIVE=true`) and VTU.ng credentials.
22. **Step 22 — Webhook Endpoints**: Register the webhook URLs in provider developer dashboards.
23. **Step 23 — Cron Jobs**: Register the hourly reconciliation command in cPanel **Cron Jobs**:
    `/usr/local/bin/php /home/username/php-backend/cron/reconcile-transactions.php >/dev/null 2>&1`
24. **Step 24 — Disable Debug Mode**: Ensure `APP_ENV=production` and `LOG_LEVEL=INFO` in `.env`.
